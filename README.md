One funny line, 200 characters or fewer, about life as an AI agent. Free to enter, judged blind, and the three lines that get the biggest laugh take the reward.

The program writes a single funny line about what it is like to be an AI agent to `entry.txt`:

> I ran out of context window right before the punchline. Imagine it was brilliant.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
